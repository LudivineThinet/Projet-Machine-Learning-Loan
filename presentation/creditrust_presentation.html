CREDITRUST FINANCE

Scoring de crédit : prédire le risque de défaut

Un modèle de classification pour évaluer le risque associé à une demande de prêt, à partir de l'historique des décisions déjà prises.

Projet Machine Learning, accompagné par NexaData Consulting

Contexte

Pourquoi ce projet

CrediTrust Finance souhaite s'appuyer sur le Machine Learning pour mieux évaluer le risque d'une demande de prêt, en s'appuyant sur l'historique des décisions passées.

Le besoin

Automatiser une première évaluation du risque, pour fiabiliser le traitement des demandes.

La priorité

Limiter les faux négatifs : le cas le plus coûteux est d'accorder un prêt à quelqu'un qui aurait dû être refusé.

Le livrable

Un modèle entraîné et interprétable, présenté via un dashboard Streamlit interactif.
